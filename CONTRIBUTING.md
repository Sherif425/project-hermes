# Contributing to Project Hermes

Contributions should improve usefulness, accuracy, clarity, or responsible reuse of Atlas and Orion work.

## Principles

- Publish only validated, original, or properly attributed material.
- Never include secrets, personal information, private infrastructure details, or unsanitized production data.
- Respect copyright, licenses, platform rules, and audience trust.
- Keep each contribution focused and update related documentation.

## Process

1. Create or update an item in `content-backlog/`.
2. Draft using an appropriate template.
3. Complete the quality and safety checklist in `docs/Quality_Standards.md`.
4. Request review before marking content as ready to publish.
5. Record the final URL, date, audience, and lessons learned in `published/`.

Use clear Markdown, descriptive filenames, and concise commit messages.
