# Monetization Pathways

Hermes prioritizes trust and evidence before revenue. Monetization should follow demonstrated capability and genuine audience value.

## Possible pathways

| Pathway | Prerequisites |
| --- | --- |
| Freelance work | Clear portfolio, scoped services, reliable delivery evidence |
| Consulting | Deep domain experience, credible case studies, professional boundaries |
| Educational products | Proven teaching materials, audience feedback, structured curriculum |
| Templates and tools | Reusable value, documentation, support plan, appropriate license |
| Sponsorship or partnerships | Consistent audience trust and disclosed relationships |

## Decision rule

Do not package unfinished learning as expertise. Start with free, useful, accurate material; develop paid offerings only when the problem, audience, and support commitment are clear.
