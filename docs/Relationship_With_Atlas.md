# Relationship with Project Atlas

Atlas is the long-term program for database administration and data engineering. Hermes turns Atlas's mature work into public professional assets.

## Examples

| Atlas milestone | Hermes assets |
| --- | --- |
| MySQL restore exercise | Recovery runbook, article, checklist, video tutorial |
| PostgreSQL failover lab | HA case study, architecture diagram, troubleshooting guide |
| Warehouse model | Data-modeling tutorial, anonymized portfolio case study |
| Spark optimization lab | Performance lesson, technical article, demonstration |
| Airflow pipeline | Orchestration guide, deployment checklist |
| Kafka streaming lab | Event-driven architecture explainer, demo video |

## Boundaries

Atlas remains the authoritative source for technical work and validation. Hermes owns audience framing, editorial quality, publishing records, and appropriate repurposing.
