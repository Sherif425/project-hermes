# Relationship with Project Orion

Orion creates Python engineering projects that automate, observe, test, and support Atlas technologies. Hermes packages validated Orion work as portfolio and educational assets.

## Examples

| Orion project | Hermes assets |
| --- | --- |
| MySQL health-check CLI | Open-source project page, walkthrough, portfolio case study |
| Backup validation tool | Tutorial, design notes, template, demo video |
| Data-quality utility | Article on testing data pipelines, documentation example |
| Cloud automation script | Architecture note, responsible automation guide |

## Boundaries

Orion owns source code, testing, releases, and engineering documentation. Hermes may summarize and promote that work but should link to the canonical repository rather than copy it.
