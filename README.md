# Project Hermes

> The publishing, portfolio, and monetization program for validated work produced by Project Atlas and Project Orion.

Project Hermes converts technical milestones into useful professional assets without duplicating the original work. Its purpose is to make expertise visible, useful, and eventually monetizable through responsible publishing.

## Mission

Transform completed Atlas and Orion work into accurate, safe, audience-focused assets such as documentation, technical articles, LinkedIn posts, videos, portfolio case studies, educational products, templates, and consulting material.

## Core workflow

```text
Atlas / Orion milestone
        ↓
Evidence and documentation are validated
        ↓
Hermes intake and asset selection
        ↓
Draft, review, sanitize, and publish
        ↓
Measure outcomes and improve reusable assets
```

## Start here

1. Read [Hermes Architecture](docs/Hermes_Architecture.md).
2. Use the [Asset Workflow](docs/Asset_Workflow.md) for every candidate.
3. Start with the templates in `templates/`.
4. Record approved ideas in `content-backlog/` and completed work in `published/`.

## Repository structure

```text
.
├── docs/             # strategy, workflow, quality and relationship guides
├── templates/        # reusable writing and case-study templates
├── content-backlog/  # planned content and product ideas
├── drafts/           # unpublished working drafts; do not store secrets
├── published/        # publication records and reusable final assets
├── portfolio/        # portfolio case-study source material
├── metrics/          # privacy-conscious performance tracking
├── README.md
├── CONTRIBUTING.md
├── CODE_OF_CONDUCT.md
└── LICENSE
```

## Relationship to Atlas and Orion

Atlas develops database administration and data engineering capability. Orion builds Python engineering solutions for those technical problems. Hermes distributes mature, validated outcomes from both programs.

See [Relationship with Atlas](docs/Relationship_With_Atlas.md) and [Relationship with Orion](docs/Relationship_With_Orion.md).
